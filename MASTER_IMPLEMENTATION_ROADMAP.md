# Master Implementation Roadmap

```text
v0.1 Reviewer
→ v0.2 Requirement
→ v0.3 Generator + Repair
→ v0.4 Effectiveness + Mutation
→ v0.5 Failure Investigation
→ v0.6 CI / PR
→ v0.7 Release Decision
→ v0.8 Production Feedback
→ v0.9 Quality Knowledge
→ v1.0 Stable Platform
```

Review precedes generation so generated tests can be judged. Requirement intelligence precedes generation so tests map to intent. Execution precedes mutation; mutation strengthens release confidence. Production feedback and Knowledge Graph arrive after traceability has real evidence.
